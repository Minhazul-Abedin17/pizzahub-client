# 🍕 PizzaHub — Frontend

**Fresh Pizza. Happy Moments.**

PizzaHub is a modern and responsive pizza ordering and delivery platform designed to provide a smooth and convenient experience for customers, vendors, and administrators. Customers can explore pizzas, place orders, and track their orders, while vendors can manage their pizza listings and customer orders. Administrators can manage users, approve pizza listings, and monitor platform activities through dedicated dashboards.

The frontend is developed using **Next.js, React, TypeScript, and Tailwind CSS**, with Shadcn UI for reusable components and Lucide React for icons. Better Auth is used for authentication, Google OAuth for social login, and Stripe for vendor premium subscriptions. The application also includes responsive layouts, interactive components, animations, and toast notifications to provide a user-friendly experience across different devices.
